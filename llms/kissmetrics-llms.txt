# kissmetrics Documentation

> Developer documentation for integrating with the Kissmetrics Customer Engagement Automation platform. This documentation gives developers and engineers everything they need to know about the Kissmetrics API and integration methods. Learn how to send data to Kissmetrics or query your data programmatically on this site.
